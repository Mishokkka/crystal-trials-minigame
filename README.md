# Кристальные Испытания: Мини-игры

Шесть коротких системно-независимых испытаний для Foundry VTT v13 (Core 13.351). GM выбирает одного или сразу двух участников, а вся остальная партия наблюдает за их аренами в реальном времени. Карточка в чате фиксирует результат испытания — все игромеханические последствия определяет GM вручную.

## Установка

1. Скопируйте папку `crystal-trials-minigame` непосредственно в `{User Data}/Data/modules/` на компьютере с сервером Foundry. Манифест должен лежать по пути `{User Data}/Data/modules/crystal-trials-minigame/module.json`.
2. Перезапустите сервер Foundry. Войдите в нужный мир под GM, откройте **Настройки игры → Управление модулями**, включите **Кристальные Испытания: Мини-игры** и сохраните настройки.
3. Под GM откройте инструменты токенов на левой панели и нажмите значок кристалла.
4. Выберите подключённого игрока (и при желании второго игрока для парного испытания рядом на экране), режим, сложность (`Лёгкая`, `Средняя`, `Сложная`, `БЕЗУМНАЯ`) и 1–5 жизней. Владельцы одного или двух выделенных токенов подставляются автоматически.
5. Для одиночной проверки без показа игрокам и без сообщения в чат выберите **Тест для GM** с галочкой **Локальный тест**.

Окно начнёт отсчёт с краткой подсказкой управления на всех клиентах. GM может в любой момент закрыть испытание кнопкой **Принудительно закрыть** в шапке оверлея. При отключении одного из участников активный GM завершает его арену с итогом «Игрок отключился».

## Режимы

| Режим | Управление и цель | Время |
| --- | --- | --- |
| `shards` · Град осколков | WASD или стрелки. Свободно маневрируйте между разрозненными кристаллами, иглами и валунами, летящими с разных сторон и под разными углами. | 10–13 с |
| `resonance` · Цветной резонанс | WASD или стрелки. При пересечении голубой волны замрите, при пересечении янтарной двигайтесь. | 10–13 с |
| `beams` · Лучи-Резонаторы | WASD или стрелки. Покиньте подсвеченные золотом полосы до плазменного выстрела. | 10–13 с |
| `gravity` · Гравитация | A/D или ←/→. Прыгайте через шипы клавишами W, ↑ или пробелом (удерживайте для высокого прыжка), нажимайте S / ↓ для быстрого спуска и не подпрыгивайте в парящие призмы. | 10–13 с |
| `timing` · Точный импульс | Нажмите пробел или кликните по арене, когда маятник в золотой зоне. При наборе нужного числа попаданий победа засчитывается сразу. | 7,8–9,8 с |
| `maze` · Лабиринт | Наведите курсор на СТАРТ и проведите точку к ФИНИШУ. После касания стены или выхода курсора из поля подведите курсор обратно к точке. | 12–18 с |

На сложностях **Сложная** и **БЕЗУМНАЯ** атаки идут плотнее и быстрее: в «Граде осколков» чаще встречаются перекрёстные залпы и вееры игл, в «Гравитации» появляются парные ряды шипов и парящие преграды, в «Точном импульсе» зона смещается и на `insane` возможен повтор направления, а в «Лабиринте» путь перекрывают 3–4 периодических затвора (пунктир — открыт, жёлтый — предупреждение, розовый — закрыт).

После попадания в режимах уклонения неуязвимость длится 0,75 секунды. В лабиринте касание стены останавливает точку и на 0,6 секунды блокирует повторный подхват.

## Настройки

- По умолчанию отсчёт длится 2 секунды, итог показывается 1600 мс, а карточка публикуется в чате. Эти настройки действуют на весь мир.
- В комплекте 13 процедурных звуков. Любой из них можно заменить через выбор аудиофайла (пустой путь отключает звук).
- Музыка на время раунда по умолчанию отключена; при выборе файла зацикливается до конца игры.
- Каждый игрок может нажать кнопку громкости прямо в шапке оверлея или включить `muteLocal` в настройках клиента.

Исходник звуков находится в `tools/generate-sounds.py`. Для повторной генерации запустите `python tools/generate-sounds.py` из папки модуля.

## Макросы GM

Выберите тип макроса **Script**.

```js
const trialModule = game.modules.get("crystal-trials-minigame");
if (!trialModule?.active || typeof trialModule.api?.openLauncher !== "function") {
  return ui.notifications.warn("Модуль «Кристальные Испытания» не активен или мир ещё не загружен.");
}
const api = trialModule.api;
```

**Открыть панель**

```js
await api.openLauncher();
```

**Запустить испытание для одного игрока (в том числе на сложности `insane`)**

```js
const player = game.users.find(user => user.active && !user.isGM);
if (!player) return ui.notifications.warn("Нет подключённых игроков.");

api.start({
  userId: player.id,
  gameType: "shards",
  difficulty: "insane",
  lives: 3,
  title: "Шквал осколков"
});
```

**Запустить парное испытание для двух игроков рядом**

```js
const players = game.users.filter(user => user.active && !user.isGM);
if (players.length < 2) return ui.notifications.warn("Нужны хотя бы два подключённых игрока.");

api.start({
  userIds: [players[0].id, players[1].id],
  gameType: "beams",
  difficulty: "hard",
  lives: 3,
  title: "Перекрёстный огонь"
});
```

**Локальный тест только для GM (без рассылки и чата)**

```js
api.start({userId: game.user.id, difficulty: "hard", localOnly: true});
```

Параметр `difficulty` принимает `easy`, `medium`, `hard` или `insane`.

**Принудительно закрыть окно у всех**

```js
api.abort();
```
